# חוברת סיכום ומיקודית לבגרות במחשבת ישראל (שאלונים 281 / 282 / 5281)

## 1. מפת הנושאים המרכזיים בבגרות
- **חטיבה א': אמונה והתגלות** — ספר הכוזרי לרבי יהודה הלוי והקדמות הרמב"ם.
- **חטיבה ב': תורת האדם, מוסר ובחירה** — שמונה פרקים והלכות תשובה לרמב"ם.
- **חטיבה ג': גאולה, ציונות דתית וארץ ישראל** — הראי"ה קוק (אורות התשובה) והגרי"ד סולובייצ'יק (קול דודי דופק).
- **חטיבה ד': תפילה, עבודת ה' ודילמות מודרניות**.

## 2. מילון מושגי יסוד בהגות היהודית
| מושג | מקור מרכזי | הגדרה ומשמעות |
| :--- | :--- | :--- |
| **העניין הא-לוהי** | ספר הכוזרי | הכוח הרוחני והנבואי המיוחד שחל על עם ישראל בארץ ישראל |
| **שביל הזהב** | רמב"ם, שמונה פרקים | המידה הממוצעת המאוזנת בכל תכונה נפשית (למשל: נדיבות בין פזרנות לקמצנות) |
| **מצוות שכליות מול שמעיות** | רמב"ם, שמונה פרקים | מצוות שהשכל מחייב בעצמו מול חוקים שנועדו לקבלת עול מלכות שמיים |
| **תשובה עילאה ותתאה** | הרב קוק, אורות התשובה | תשובה מיראה ותיקון החטא לעומת תשובה מאהבה והתעלות הנפש וההוויה |
| **ברית גורל וברית ייעוד** | הרב סולובייצ'יק, קול דודי דופק | שותפות הגורל והסבל (מצרים) לעומת השותפות הערכית והרוחנית של מסירת התורה (סיני) |
